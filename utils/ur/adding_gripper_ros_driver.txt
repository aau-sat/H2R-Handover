INSTRUCTIONS FOR ADDING AND CONTROLLING THE ROBOTIQ GRIPPER WITHIN THE UR ROS DRIVER FRAMEWORK

Settings:
- ROS2 Humble with Ubuntu 22
- Robotiq 2f85 or 2f140 gripper 
- UR robot with external control 


Requirements:
- Install the UR ros2 driver, if not already done: https://github.com/UniversalRobots/Universal_Robots_ROS2_Driver 
- Install the Robotiq ros2 driver: 
	- clone the repository (checkout correct branch (humble)): https://github.com/PickNikRobotics/ros2_robotiq_gripper
	- install the dependencies: $ rosdep install --from-paths src --ignore-src -r -y
	- do a colcon build. You will most likely get an error about the serial interface. If not, continue. If yes:
		- add this repo to your workspace: https://github.com/RoverRobotics-forks/serial-ros2 
		- modify the CMakeLists.txt file by adding the following instruction after the find_package one: set(CMAKE_POSITION_INDEPENDENT_CODE ON)

- Install (using the teach pendant) the rs485-1.0.urcap found in the resources folder of the ur robot driver.
- In the Settings folder on the UR teach pendant, under Security > General, make sure that the voice "Disable inbound access to additional interfaces" is set to 1. You might 
  need a password to change that

Operation:
- Make sure to have external control running on the UR.
- Make sure that in Installation > Tool I/O it is selected that interfaced is controlled by User
- Start the tool communication with: $ ros2 run ur_robot_driver tool_communication.py --ros-args -p robot_ip:=<your_ip> -p device_name:=/tmp/ttyUR
- Check functionalities by launchng the robotiq gripper control with: $ ros2 launch robotiq_description robotiq_control.launch.py

if it works congrats! You can send open/close commands with the dedicated ros2 action (check ros2 action list)


INSTRUCTIONS FOR CONTROLLING THE ROBOTIQ GRIPPER AND THE ROBOT VIA MOVEIT
- Make sure to have external control running on the UR.
- Make sure that in Installation > Tool I/O it is selected that interfaced is controlled by User

- TERMINAL 1: Start the tool communication with: $ ros2 run ur_robot_driver tool_communication.py --ros-args -p robot_ip:=192.168.2.12 -p device_name:=/tmp/ttyUR -p baud_rate:=115200

- TERMINAL 2: Start the UR robot driver with the custom configuration that accounts for the gripper:
$ ros2 launch ur_robot_driver ur_control.launch.py   ur_type:=ur3e   robot_ip:=192.168.2.12   use_tool_communication:=false   launch_rviz:=false   description_file:=/home/christian/rgmc-2026/utils/ur/src/ur_custom/urdf/ur_custom_gripper.urdf.xacro  runtime_config_package:=ur_custom  controllers_file:=ur_robot_gripper_combined_config.yaml kinematics_params_file:="${HOME}/rgmc_robot_calibration.yaml"

UPD: this works:
ros2 launch ur_robot_driver ur_control.launch.py   ur_type:=ur3e   robot_ip:=192.168.2.12   use_tool_communication:=false   launch_rviz:=false   description_file:=/home/christian/rgmc-2026/utils/ur/src/ur_custom/urdf/ur_custom_gripper.urdf.xacro  runtime_config_package:=ur_custom  controllers_file:=ur_custom_controllers_gripper.yaml kinematics_params_file:=/home/christian/rgmc-2026/utils/ur/src/ur_custom_gripper_moveit_config/calibration/ur3e.yaml headless_mode:=true

- TERMINAL 3: Start Moveit:
$ ros2 launch ur_custom start_real_robot_with_gripper.launch.py
